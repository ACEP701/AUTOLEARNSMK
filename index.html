Estimasi: 45 Menit

1. Langkah Hisap (Intake Stroke: 0° – 180°)

Piston bergerak turun dari TMA ke TMB. Katup masuk (kiri) terbuka sehingga campuran udara dan bahan bakar terhisap masuk ke dalam silinder akibat kevakuman. Katup buang (kanan) tertutup rapat.

GEJALA PADA KENDARAAN:
  • Mesin tersendat (brebet) saat pedal gas diinjak tiba-tiba.
  • Konsumsi bahan bakar menjadi sangat boros dan keluar asap hitam dari knalpot.
  • Putaran stasioner (idle) mesin kasar atau mudah mati.
NILAI STANDAR MULTIMETER:

Tegangan Referensi (Vc): 5,0 V | Sinyal PIM saat Idle: 1,1 – 1,6 V | Saat Kunci ON (Mesin Mati): 3,4 – 4,0 V

PEMBACAAN KERUSAKAN SAAT INI:

Sinyal PIM terbaca 4,98 V terus-menerus (Open Circuit pada jalur massa E2 atau selang vakum terlepas).

SOP LANGKAH PEMERIKSAAN & PERBAIKAN BENGKEL:
  1. Periksa kondisi selang vakum dari intake manifold ke sensor MAP (pastikan tidak retak, terlipat, atau terlepas).
  2. Periksa konektor 3-pin sensor MAP dari kotoran atau korosi.
  3. Ukur tegangan pin Vc (5V) dan kontinuitas pin massa (E2) menuju ECU menggunakan multimeter digital.
  4. Jika selang dan perkabelan normal namun tegangan sinyal tidak berubah saat diberi kevakuman, ganti unit Sensor MAP dan lakukan Clear DTC.

Langkah 2: Kode Google Apps Script (doPost)

Di Google Sheets, klik menu Ekstensi → Apps Script, hapus kode bawaan, tempel kode di bawah ini, lalu klik Terapkan (Deploy) → Deployment baru → Jenis: Aplikasi Web → Yang memiliki akses: Siapa saja (Anyone). 

function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    
    if (sheet.getLastRow() === 0) {
      sheet.appendRow([
        "Timestamp", "Event", "Nama Siswa", "Kelas / NIS",
        "Asal Sekolah", "Progres Modul", "Daftar Modul",
        "Skor UKK", "Jumlah Benar", "Status Kelulusan",
        "Aktivitas Simulator"
      ]);
    }
    
    sheet.appendRow([
      data.timestamp || new Date().toLocaleString("id-ID"),
      data.event || "-",
      data.nama || "Anonim",
      data.kelas_nis || "-",
      data.sekolah || "-",
      data.progres_modul || "0/4 Modul (0%)",
      data.daftar_modul || "-",
      data.skor_ukk !== undefined ? data.skor_ukk : "-",
      data.jumlah_benar || "-",
      data.status_kelulusan || "BELUM KOMPETEN",
      data.aktivitas_simulator || 0
    ]);
    
    return ContentService
      .createTextOutput(JSON.stringify({ status: "success" }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService
      .createTextOutput(JSON.stringify({ status: "error", message: err.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

Online-kan Website Ini & Daftarkan ke Google

Ketik alamat website rencana Anda di bawah ini (misal: https://username.github.io/autolearn-smk atau https://autolearn-smk.netlify.app), lalu unduh 3 file siap upload. Jika Anda sudah mengisi URL Web App Google Sheets di Panel 1, file index.html yang terunduh otomatis menyimpan URL tersebut secara permanen!

01

Upload ke Hosting Gratis

Unggah ketiga file (index.html, robots.txt, sitemap.xml) ke:

  • • GitHub Pages: Buat repositori publik, unggah 3 file di root, lalu aktifkan Settings → Pages → Branch: main.
  • • Netlify Drop (app.netlify.com/drop): Seret folder ke browser, website langsung online dengan HTTPS gratis.
02

Verifikasi Google Search Console

Daftarkan alamat website Anda agar robot perayap Google (Googlebot) menemukannya:

  • 1. Buka search.google.com/search-console dengan akun Google Anda.
  • 2. Pilih properti Awalan URL (URL Prefix) dan masukkan alamat domain aktif Anda.
  • 3. Selesaikan verifikasi kepemilikan (Tag HTML atau file verifikasi).
03

Kirim Sitemap & Minta Indeks

Percepat kemunculan portal pembelajaran di halaman pencarian Google:

  • 1. Buka menu Peta Situs (Sitemaps) di Google Search Console, ketik sitemap.xml lalu klik Kirim.
  • 2. Gunakan kolom Inspeksi URL di atas, masukkan URL utama, lalu klik Minta Pengindeksan.
